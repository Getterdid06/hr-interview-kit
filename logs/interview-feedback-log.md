# Interview Feedback Log

Add one entry per interview, newest at the bottom. Keep the file in the internal, interviewer-only folder. Retain hiring records at least **1 year** (29 CFR 1602.14), or longer if a charge or lawsuit is pending.
**Do not record** protected-class information (age, race, religion, national origin, disability, pregnancy, family status, etc.).

## Template (copy this)
```markdown
### [YYYY-MM-DD] — [Role file] — Candidate ID: [initials or ATS ID]
- Interviewers:
- Position tuning used: seniority=__, project_type=__, sections on=__
- Knockouts triggered: none / [which + evidence]
- Scores (1–5): | Q-ID | Score | One-line evidence |
- ★ minimum met: Y/N   Average: __   Threshold: __
- Practical test (if any): raw __/30 → __ /5; time used __ min
- Recommendation: GO / HOLD / NO-GO
- Decision made (by hiring manager): hired / not hired / pending
- Notes on question quality (confusing? too easy? everyone scores 5?):

#### Follow-up (fill later)
- 30-day: on track? [Y/N] + manager note
- 90-day: performance rating 1–5 + retained Y/N
- 180-day: performance rating 1–5 + retained Y/N; did the interview prediction hold?
```
